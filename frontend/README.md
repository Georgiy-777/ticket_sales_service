# TeaCinema Frontend

Эта дериктория содержит фронтенд-часть проекта, разработанную в рамках курса по микросервисной архитектуре.

Фронтенд реализован на Next.js и представляет собой клиентское приложение для сервиса продажи билетов в кино: просмотр фильмов, сеансов, выбор мест и оформление бронирований.

## Зависимость от бэкэнда

Для корректной работы фронтенда необходимо предварительно развернуть бэкэнд проекта.

Полный бэкэнд с исходным кодом и подробными объяснениями доступен в видео на ютубе и для скачивания [на сайте по подписке]()https://teacoder.ru/premium.

## Установка и запуск

1. Установите зависимости:

```bash
npm install
# или
yarn install
# или
bun install
```

2. Создайте `.env` и добавьте необходимые переменные окружения, например:

```env
NEXT_PUBLIC_API_URL=http://localhost:4000
NEXT_PUBLIC_MEDIA_URL=http://localhost:4200
```

3. Запустите фронтенд:

```bash
npm run dev
# или
yarn run dev
# или
bun run dev
```
